# Data catalog

**Key finding:** EcoTrace never collected primary data. There are **no** field surveys, institution
records, customer data, pickup logs or measured waste quantities on this laptop. "Datasets" here means
small reference tables, and those were **generated by a chatbot**. Their numbers are **unverified
estimates** and must not be cited as facts.

Data that real users may have entered in the Supabase projects was not inspected (live service, out of scope).

## Rules for adding data later

No real institution data, personal data (names, phones, photos of people), API keys or `.env` files
in this repo. Store pilot data in Supabase with RLS, or in a private, encrypted location, and record
consent.
