# Step 1: Stop Thinking in Activities

Think in **Environmental Impact Units**

Every eco-friendly activity ultimately affects one of only 4 environmental domains:

| Domain         | What it impacts       | Example         |
| -------------- | --------------------- | --------------- |
| Energy         | Emissions             | Solar plant     |
| Water          | Freshwater use        | Rain harvesting |
| Waste          | Landfill & methane    | Recycling       |
| Land / Ecology | Carbon & biodiversity | Tree plantation |

Everything fits into these 4.

---

# Step 2: For Each Domain, Define a Standard Verification Template

Instead of building separate logic for solar, composting, etc.,
you define a **5-layer verification structure** for every activity.

Every activity must answer:

1️⃣ Asset Exists
2️⃣ Asset Is Operating
3️⃣ Output Is Measured
4️⃣ Output Is Cross-Verified
5️⃣ Environmental Impact Is Calculated

That’s your universal model.

---

| Layer          | Verification Method          |
| -------------- | ---------------------------- |
| Exists         | Installation certificate     |
| Operating      | Daily inverter logs          |
| Measured       | kWh generated                |
| Cross-verified | Electricity board net export |
| Impact         | CO₂ avoided calculation      |

# Step 3: Convert All Metrics to Standard Impact Outputs

Each activity produces different raw data:

* kWh
* Liters
* Kg
* Number of trees

But your system should convert everything into:

| Output Type           | Why Important            |
| --------------------- | ------------------------ |
| CO₂ equivalent        | universal climate metric |
| Water saved (m³)      | water sustainability     |
| Waste diverted (tons) | landfill reduction       |
| Biodiversity index    | ecological impact        |

Now everything becomes comparable.

# Step 5: Verification Scoring Layer (Very Powerful)

For each activity, assign verification strength:

| Level   | Meaning                       |
| ------- | ----------------------------- |
| Level 1 | Self-reported only            |
| Level 2 | Supporting documents uploaded |
| Level 3 | External party confirmation   |
| Level 4 | Automated meter integration   |
| Level 5 | Third-party auditor sign-off  |

Now auditors can instantly see:
Which claims are strong, which are weak.

That increases credibility dramatically.
